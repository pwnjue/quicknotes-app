# QuickNotes

QuickNotes is a simple web-based note-taking application that helps users create, organise, search and manage notes. Users can assign notes to Personal, Work or Study categories, delete notes they no longer need, and keep their notes saved in the browser.

## Features

- Add notes with a maximum of 200 characters.
- Organise notes into Personal, Work and Study categories.
- Search notes without case sensitivity.
- Delete individual notes.
- Validate empty notes and notes exceeding 200 characters.
- Display the number of saved notes.
- Save notes using browser localStorage.
- Restore saved notes after refreshing the page.
- Display the creation date and time of each note.
- Responsive layout for smaller screens.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser localStorage

## How to Run Locally

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Start adding, searching and managing your notes.

No additional software or server is required for basic use.
